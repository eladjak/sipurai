---
name: sipurai-print
description: Prepare or review a Sipurai Hebrew picture book for physical printing, including RTL spreads, approved pointed text, covers, owner-only scans and preflight.
---

Use the renderer and checks in [the print edition guide](../../../docs/PRINT-EDITION.md). Start with the owner's print-edition export and the original illustration sources. Keep the book and the generated PDFs outside the repository.

1. Record each character's distinguishing features. Use a reference sheet when generating scenes, the dedication vignette and the closing picture. Compare each appearance with the sheet. Give the last picture a new action connected to this story.
2. Decide which scenes need one page and which need a single panoramic asset. Place the face, object that advances the plot, and words in the safe part of the trimmed page. Review each pair physically facing, even page on the right. At the beginning and end, include the adjacent inside cover.
3. Have a proper Hebrew pointing engine propose text, resolve homographs in context, and let the parent review the exact version. Preserve the unpointed source and approvals. Check line endings and quotation marks in the final PDF render. Use review-only mode for unapproved proofs.
4. Check the actual page count against the four-page signature and recalculate the spine. Include the title, optional dedication, copyright, exterior folios, back copy, scan and an intentional ending. The supplier barcode belongs at the bottom near the horizontal center of the left inside cover in its current photographed example. Verify its position on the vendor template.
5. Run the render and independent check commands in the guide. Inspect each facing PNG and the outside and inside wraps. Decode the printed QR from the final raster and verify anonymous/private, shared and owner access through the normal reader. Public viewing follows the owner's live sharing policy.
6. Record native resolution separately from resampled output. Record the ICC profile and whether it matches the selected stock. Production signoff also requires an approved material configuration and a physical proof on that stock. Only the parent can approve the wording. Keep the digital proof when either approval is outstanding.
