# בדיקת קורא הלילה עם ילד או ילדה

הבדיקה מיועדת להורה ולשני טווחי גיל: 3–4 ו־5–6. הקדישו כעשר דקות לכל ילד, בנפרד. אין צורך לבדוק את הילד: בודקים אם המסך ברור לו.

1. פתחו סיפור מוכן בטלפון. בקשו מהילד להתחיל לקרוא או להאזין, בלי להצביע על הכפתורים.
2. בקשו לעבור לעמוד הבא ולחזור. צפו אם הילד מזהה את החצים ואת הנקודות, ואם הוא מנסה גם להחליק.
3. בקשו לעצור את ההקראה ולהשמיע את העמוד שוב. שימו לב אם ברור מה כל כפתור עושה.
4. תנו לילד להמשיך לבד כמה דקות. שימו לב ללחיצות מקריות, להיסוס, לתסכול ולעוצמת האור והקול.
5. בסוף, ההורה מחזיק את כפתור היציאה שתי שניות. בדקו אם ההוראה והטבעת ברורות להורה ואם הילד לא יצא בטעות.

רשמו גיל, מכשיר ושפה; לכל משימה רשמו הצליח לבד / נזקק לרמז / לא הצליח, מה הילד אמר או עשה, וכמה זמן היסס. רשמו גם כל תקלה או רגע מהנה. אל תכללו שם ילד או פרטים מזהים בדיווח. העבירו את הממצאים לבעל המוצר לפני שחרור.
