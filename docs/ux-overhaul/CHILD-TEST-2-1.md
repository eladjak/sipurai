# בדיקת קורא הלילה עם ילד או ילדה

הבדיקה מיועדת להורה ולשני טווחי גיל: 3–4 ו־5–6. הקדישו כעשר דקות לכל ילד בנפרד. לא בודקים את הילד, אלא אם המסך ברור לו. הכינו סיפור מוכן בטלפון, בעוצמת קול נוחה, והישארו ליד הילד.

1. פתחו את הסיפור ובקשו מהילד להתחיל לקרוא או להאזין, בלי להצביע על הכפתורים. שימו לב מה הוא עושה קודם ואם הוא מבין איך מפעילים הקראה.
2. בקשו לעבור לעמוד הבא ולחזור. צפו אם הוא מזהה את החצים ואת הנקודות, ואם הוא מנסה גם להחליק.
3. בקשו לעצור את ההקראה ולהשמיע שוב את העמוד. רשמו אם הוא הצליח לבד או נזקק לרמז.
4. תנו לילד להמשיך לבד כמה דקות. שימו לב ללחיצות מקריות, להיסוס, לתסכול ולעוצמת האור והקול.
5. שימו לב אם הילד מחליק מקצה המסך ומפעיל את חזרת הדפדפן. פעולה זו עלולה להוציא מהסיפור גם בלי לחיצה על יציאה. אפשר להפעיל מראש את נעיצת המסך או הגישה המודרכת במכשיר; בדקו בהוראות המכשיר איך מפעילים ומשחררים אותה.
6. בסוף החזיקו בעצמכם את כפתור היציאה שתי שניות. בדקו אם ההוראה והטבעת ברורות ואם הילד יצא בטעות במהלך הקריאה.

לכל ילד רשמו את טווח הגיל, סוג המכשיר ושפת הממשק. ליד כל משימה כתבו: הצליח לבד / נזקק לרמז / לא הצליח, מה הילד אמר או עשה, וכמה זמן היסס. ציינו גם אם מחוות החזרה הוציאה מהסיפור, וכל תקלה או רגע מהנה. אל תכללו שם ילד או פרטים מזהים בדיווח. העבירו את הממצאים לבעל המוצר לפני השחרור.
